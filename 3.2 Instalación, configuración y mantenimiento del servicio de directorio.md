# 3.2 Instalación, configuración y mantenimiento del servicio de directorio

# 1 Actualizar Ubuntu

sudo apt update



sudo apt upgrade -y


# 2 Instalar OpenLDAP

sudo apt install slapd ldap-utils -y

# 3 Configurar slapd

Ejecuta:

sudo dpkg-reconfigure slapd

Pregunta	Respuesta:

Omitir configuración OpenLDAP	No

Nombre DNS	serveisbcn.com

Organización	ServeisBCN

Contraseña administrador	admin123

Confirmar contraseña	admin123

Backend	MDB

¿Borrar base de datos?	No

¿Mover base antigua?	Sí

# 4 Comprobar que el servicio funciona

sudo systemctl status slapd

# 5 Verificar puerto LDAP

sudo ss -tunlp | grep 389

# 6 Probar búsqueda LDAP

ldapsearch -x -LLL -H ldap:/// -b dc=serveisbcn,dc=com
