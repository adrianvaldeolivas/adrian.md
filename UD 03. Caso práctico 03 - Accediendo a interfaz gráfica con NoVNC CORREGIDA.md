# UD 03. Caso práctico 03 - Accediendo a interfaz gráfica con NoVNC

# 1-Instalación de Docker

sudo apt update

sudo apt install docker.io -y

Activar Docker:

sudo systemctl start docker

sudo systemctl enable docker

# 2-Comprobar que funciona:

docker --version

# 3. Preparar y ejecutar el contenedor

Vamos a usar una imagen ya preparada que incluye VNC + NoVNC.

 Ejecutar el contenedor

# 4. Acceder a la interfaz gráfica

Abre tu navegador

Escribe: http://localhost:8080/vnc.html

# 5. Finalizar la práctica

Para cerrar:

Vuelve a la terminal

Pulsa: Ctrl + C
