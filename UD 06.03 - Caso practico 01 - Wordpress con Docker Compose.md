# UD 06.03 - Caso practico 01 - Wordpress con Docker Compose

# PASO 1. Crear el directorio del proyecto

Creamos una carpeta para el caso práctico y entramos en ella:

mkdir wordpress-docker
cd wordpress-docker

# PASO 2. Crear el fichero docker-compose.yml

Creamos el archivo:

nano docker-compose.yml

Pegamos exactamente este contenido:

version: "3.9"

services:
  db:
    image: mariadb:10.11.2
    volumes:
      - db_data:/var/lib/mysql
    restart: always
    environment:
      MARIADB_ROOT_PASSWORD: somewordpress
      MARIADB_DATABASE: wordpress
      MARIADB_USER: wordpress
      MARIADB_PASSWORD: wordpress

  wordpress:
    depends_on:
      - db
    image: wordpress:latest
    ports:
      - "8000:80"
    restart: always
    environment:
      WORDPRESS_DB_HOST: db:3306
      WORDPRESS_DB_USER: wordpress
      WORDPRESS_DB_PASSWORD: wordpress
      WORDPRESS_DB_NAME: wordpress

volumes:
  db_data:

Guardamos y salimos:

# PASO 3. Lanzar el sistema (WordPress + MariaDB)

Desde el mismo directorio ejecutamos:

docker compose up -d

# PASO 4. Comprobar que los contenedores están en marcha

Ejecutamos:

docker compose ps

# PASO 5. Acceder a WordPress

Abrimos el navegador y entramos en:

http://localhost:8000

# PASO 6. Parar el sistema

Para detener y eliminar los contenedores:

docker compose down

# PASO 7. Volver a lanzar el sistema

Si queremos arrancarlo de nuevo:

docker compose up -d

# PASO 8. (Opcional) Ver volúmenes creados

Para comprobar el volumen de la base de datos:

docker volume ls
