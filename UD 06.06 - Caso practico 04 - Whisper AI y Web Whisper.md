# UD 06.06 - Caso practico 04 - Whisper AI y Web Whisper

# 1-Requisitos previos

Antes de empezar, debemos tener instalado:

Docker

Docker Compose

Podemos comprobar Docker con:

docker --version

Y Docker Compose con:

docker compose version

# 2-Obtener el proyecto Whisper Web

Opción A: Clonar el repositorio (si usamos Git)

Ejecutamos el siguiente comando:

git clone https://codeberg.org/pluja/web-whisper

Entramos en el directorio del proyecto:

cd web-whisper

Opción B: Usar el ZIP del curso

Si usamos el archivo ZIP proporcionado en el curso:

Descomprimimos el archivo

Abrimos una terminal dentro de la carpeta web-whisper

# 3-Crear el archivo docker-compose.yml

Dentro del directorio del proyecto, copiamos el archivo de ejemplo:

cp example.docker-compose.yml docker-compose.yml

Este archivo define los contenedores que se van a levantar con Docker.

# 4-Crear el archivo .env

Ahora copiamos el archivo de variables de entorno:

cp example.env .env

# 5-Lanzar Whisper AI y Whisper Web

Una vez preparados los archivos, ejecutamos:

docker compose up --build -d

Este comando:

Construye las imágenes necesarias (--build)

Levanta los contenedores en segundo plano (-d)

# 6-Comprobar que los contenedores están activos

Podemos verificar que todo está funcionando con:

docker ps

# 7-Acceder a Whisper Web

Abrimos un navegador web y accedemos a:

http://localhost:3000

# 8-Parar los contenedores (opcional)

Cuando queramos detener el servicio, ejecutamos:

docker compose down
