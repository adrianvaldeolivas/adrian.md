# UD 06.07 - Caso practico 05 - Bot de Telegram con Whisper AI

# 1-Comprobamos Docker con:

docker --version

Y Docker Compose con:

docker compose version

# 2-Crear el bot con BotFather

Abrimos Telegram.

Buscamos el bot @BotFather.

Iniciamos conversación y escribimos:

/newbot

Indicamos:

Nombre del bot

Nombre de usuario (debe acabar en bot)

Guardamos el TOKEN que nos devuelve BotFather.
📖 Este token será necesario más adelante.

# 3-Obtener ID de usuario

Buscamos el bot @RawDataBot.

Le enviamos un mensaje.

Copiamos el valor:

message.from.id

# 4-Obtener ID de grupo

Añadimos @RawDataBot al grupo.

Enviamos un mensaje en el grupo.

Copiamos el ID del grupo, que será algo como:

-123456789

📖 Los IDs de grupo siempre empiezan por -.

# 5-Descargar el proyecto del bot Whisper

Clonamos el repositorio oficial del bot:

git clone https://github.com/sergarb1/telegram-bot-whisper-cpp

Entramos en el directorio:

cd telegram-bot-whisper-cpp

📖 En el curso, este repositorio también puede venir en formato .zip.


# 6-Configurar el archivo .env

Editamos el archivo .env con el editor que queramos, por ejemplo:

nano .env

Configuramos las siguientes variables:

6.1 Token del bot


TELEGRAM_BOT_TOKEN=TU_TOKEN_AQUI

6.2 IDs permitidos

ALLOWED_CHAT_IDS=123456789,-123456789

📖 También se puede permitir a todos los usuarios con:

ALLOWED_CHAT_IDS=*

6.3 Modelo de Whisper

WHISPER_MODEL=small

📖 Se recomienda small como máximo para estas pruebas.

6.4 Idioma del audio

AUDIO_LANGUAGE=auto

Guardamos el archivo y salimos.

# 7-Lanzar el bot con Docker Compose

Una vez configurado todo, ejecutamos:

docker compose up --build -d

# 8-Comprobar que el contenedor está activo

Ejecutamos:

docker ps

# 9-Probar el bot de Telegram

9.1 Mensaje directo

Enviamos una nota de voz o archivo de audio al bot desde un usuario autorizado.

El bot responderá con la transcripción del audio.

9.2 En un grupo

Añadimos el bot al grupo.

Damos permisos de lectura.

Enviamos un audio.

La transcripción se mostrará en el grupo.

# 10-Parar el bot

Si queremos detener el servicio:

docker compose down
